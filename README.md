# SQL Atlas

A modern trilingual SQL learning website covering foundational and advanced SQL syntax with examples, usage notes, filters, and practical query templates.

## Features

- Chinese, English, and French language switching
- 31 SQL syntax topics from `SELECT` to window functions, transactions, indexes, CTEs, JSON, and `EXPLAIN`
- Search, level filters, and category filters
- Query execution order roadmap
- Business SQL playbook templates
